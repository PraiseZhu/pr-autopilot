# 七个固定检查面定义（§1.1b ②）

> R7 白名单文件：周会收紧类提案可追加检查项，不得删除既有项（删除 = 扩权特征，R2 拦截）。

| 面 | 内容 | 备注 |
|---|---|---|
| A 正确性 | 状态机分支/竞态/交互阻断/unhandled promise；兜底一切 active-path 正确性（兼容、迁移、构建集成、资源泄漏） | 双 lens 主战场 |
| B UI 规范+无障碍 | 设计值 vs px、token、44pt 触达、读屏/焦点/lang | 仅当 match.mjs 判非 UI 才许 n_a |
| C 测试 | 单测绿灯、断言鲁棒性、QA 工件同步 | demo 工件当代码审 |
| D 文档一致性 | 注释引用的章节/文件存在性、索引收录、描述与实现一致 | 默认只产建议，仅「索引缺失」可阻塞 |
| E 安全/凭证 | 授权链路是否被误删、隐私/统计开关、密钥 | always-on 窄门 checklist，不占轮次 |
| F 范围合规 | owned_paths、禁碰 CI 路径、force refspec | 脚本预检，reviewer 只复核 |
| G 声称核实 | PR 描述声称「已测试/已验证」的，证据是否真实存在 | 双审最高价值命中面；delta 轮不豁免 |

明确不设：产品语义、软件架构、日志（并入 A）。
